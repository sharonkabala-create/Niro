# Niro · גרסת ווב ראשונה

אפליקציה אמיתית שעובדת בדפדפן של הטלפון: מיקום אמיתי, צ'אט בזמן אמת, קבוצות לפי מקום, שיחות פרטיות באישור ונעילה כשמתרחקים.

## מה יש בתיקייה

| קובץ | מה הוא |
|---|---|
| `schema.sql` | מסד הנתונים. מדביקים פעם אחת ב-Supabase |
| `index.html` | האפליקציה עצמה |
| `config.js` | הכתובת והמפתח הציבורי של השרת שלך (כבר ממולאים) |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | אייקון והתקנה למסך הבית |

## הפעלה, פעם אחת

### 1. מסד הנתונים
1. ב-Supabase: **SQL Editor** ← **New query**
2. להדביק את כל התוכן של `schema.sql` וללחוץ **Run**
3. אמור להופיע `Success. No rows returned`

### 2. כניסה בלי אימייל
**Authentication** ← **Sign In / Providers** ← להפעיל **Allow anonymous sign-ins** ← Save

### 3. להעלות לאוויר (Netlify, חינם)
1. לחלץ את קובץ ה-zip לתיקייה
2. להיכנס ל-https://app.netlify.com/drop ולהתחבר עם GitHub
3. לגרור את **התיקייה** לחלון
4. תוך כמה שניות מקבלים כתובת כמו `something.netlify.app`
5. אפשר לשנות את השם: **Site configuration** ← **Change site name** ← למשל `niro-app`

### 4. לנסות
- לפתוח את הכתובת בטלפון, להירשם עם שם ולאשר מיקום
- לבדוק עם עוד טלפון או חבר שנמצא לידך. אפשר גם טלפון ומחשב נייד
- באייפון: **שיתוף** ← **הוספה למסך הבית**. באנדרואיד: תפריט ← **התקן אפליקציה**

## איך זה עובד מאחורי הקלעים
- כל ההחלטות (מי קרוב, מי רואה איזו הודעה, מתי שיחה ננעלת) מתקבלות בשרת, לא בטלפון. אי אפשר לעקוף אותן.
- אף משתמש לא מקבל מיקום של אחר, רק מרחק מעוגל ל-10 מטר. הכיוון ברדאר אקראי.
- שיחה פרטית ננעלת כשהמרחק גדול מהטווח שנבחר בבקשה, או כשאחד הצדדים לא נראה 5 דקות. ההודעות שלה נמחקות מיד.
- הודעות בכיכר נראות 6 שעות ונמחקות אחרי 24. הודעות בקבוצות נמחקות אחרי 48 שעות.
- אפשר לחסום ולדווח. הדיווחים נשמרים בטבלה `reports` (Table Editor ב-Supabase).

## מגבלות של גרסת הווב
- עובד כשהאפליקציה פתוחה. אם סוגרים אותה ליותר מ-5 דקות, המשתמש נעלם מהרדאר והשיחות שלו ננעלות.
- אין עדיין התראות פוש.
- תמונות שנשלחו נשארות באחסון גם אחרי שהשיחה נמחקת (הקישור אליהן נמחק). כדאי להוסיף ניקוי אוטומטי בהמשך.

## לפני השקה לציבור
- תנאי שימוש ומדיניות פרטיות (מומלץ עם עורך דין)
- הגנה מבוטים: **Authentication** ← **Attack Protection** ← CAPTCHA
- מישהו שעובר על הדיווחים
